Animated Monterey (Intel macOS 12.7.6 target)

A standalone desktop-only adaptation inspired by vlzuiev/animated (MIT license):
https://github.com/vlzuiev/animated
This is not the upstream app or a verified build of its source.

1. Unzip.
2. Open Terminal, type bash followed by a space, drag install.command into Terminal, press Return.
3. If Command Line Tools are missing, run xcode-select --install and retry.
4. Click the cricket icon in the menu bar to choose any MP4/MOV, pause or quit.
5. Optional: System Preferences > Users & Groups > Login Items > add Animated Monterey from ~/Applications.

Limitations: desktop only, not animated lock screen. Video may use significant battery/CPU on older Intel Macs. Tested by code review only, not compiled on a Mac. If video appears in front of icons, quit via menu bar and report the issue.
